## 👋 About

Hi, this is **Crossing Dead Development (CDD)**.

CDD is currently a one-person studio run by me, **EvansGoethe**. This organization gathers everything I'm working on — game extension content, community bots, and (eventually) indie games.

## 🎮 What We Do

- **Minecraft Extension Content**
  - Mods (Fabric)
  - Plugins (Paper)
  - Resource Packs
- **Discord Bot Development**
  - Community tools & bots
- **Desktop Tools**
  - Utilities for the games we play

## 🚀 Roadmap

- Finish Phase 3 of **Limbus E.G.O Fabric** (spindle gacha / shop chests, final extractor textures)
- Indie game development

Bringing Limbus Company's E.G.O weapons and gifts into Minecraft 1.21.4.

| Project | Description | Latest | Tech |
| --- | --- | --- | --- |
| [Limbus E.G.O](https://github.com/Crossing-Dead-Development/Limbus-E.G.O) | **Paper plugin** (unified): 12-attribute system, sanity (SAN), 8 E.G.O weapons, 80 E.G.O gifts, extraction / spindle gacha / shop chests | [v1.4.1](https://github.com/Crossing-Dead-Development/Limbus-E.G.O/releases/latest) | Java / Paper |
